# Portfólio Derich Studio

Portfólio de Gabriel Derich Freitas, com estudos de caso da Caxtros Barber e do portal Estaca Messejana.

## Estrutura

- `dist/index.html`: página inicial
- `dist/caxtros.html` e `dist/estaca.html`: páginas dos projetos
- `dist/style.css`, `dist/site.js` e `dist/hero-gradient.js`: estilos e interações
- `dist/images/`: imagens locais usadas nas páginas

O site é estático. Não precisa de React, instalação de pacotes ou banco de dados.

## Abrir no computador

Na pasta do repositório, execute:

```bash
python3 -m http.server 8000 --directory dist
```

Depois abra `http://localhost:8000`. Também é possível publicar o conteúdo de `dist` em uma hospedagem estática.
